# FS-1 pre-registration: implementation details (2026-11-04, ET)

Committed before any FS-1 number exists. This file fixes the details that
`docs/folding-math-scout.md` §4 (FS-1) left open. It does not change H1, the
prediction, the data, the controls or the FAIL criteria in §4. Where §4 and
this file disagree, §4 wins.

## Signal handling
- Each record: first 2^17 = 131 072 samples, mean removed; the mean is stored
  as a float64 in the header. Relative error is
  `‖x − x̂‖₂ / ‖x − mean(x)‖₂`, measured on the **decoded** output (every
  stream is decoded back and the error is computed from that). Max-abs error
  is reported in the same units (g for CWRU).
- CWRU records 97, 109, 122, 135, 213, 226, 238 (drive-end channel), loaded
  only after the SHA-256 pin check, no download.
- Secondary (reported, not counted): Paderborn KA04 `_1` for the 4 conditions
  (vibration_1, 64 kHz), MD5/SHA-256 pinned cache, no download.

## Integer stream coder (shared by baseline and hybrid residual)
- Transforms: raw, first difference, order-2 linear predictor (LPC2).
  LPC2 = least-squares a1, a2 on the integer sequence, rounded to Q14
  integers (stored, 8 bytes); prediction `(a1·k[n−1] + a2·k[n−2] + 2^13) >> 14`;
  first two samples passed as-is.
- Integer width: smallest of int8 / int16 / int32 that holds the transformed
  stream (little endian).
- Coders: zstd level 22 (Python `zstandard`, version logged; same level as
  `zstd -19 --ultra -22` reaches), xz `-9e`, gzip `-9` (mtime 0), bz2 `-9`.
- Every combination is tried; the smallest is kept and its choice is stored
  in 3 header bytes.
- "No-predictor baseline" = best over raw and first difference only.
  "Predictor baseline" = best over all three transforms. The comparator for
  F1 and F3 is the predictor baseline (best of all). F2 compares the two.

## Baseline
- Uniform quantizer `k = round((x − mean)/q)`. q is found by bisection on
  log q (80 steps max) until the decoded relative error is within ±1 % of
  ε = 3·10⁻³. Bisection uses only the quantization error (independent of the
  coder); the final stream is then coded and decoded to confirm.
- Stream bytes = magic(4) + n(4) + mean(8) + q(8) + integer stream
  (choice bytes, LPC coefficients if used, compressed payload).

## Hybrid (QTT structure + coded residual)
- s = TT-SVD (Oseledets 2011, Alg. 1) of (x − mean) reshaped to (2,)*17,
  truncated to max rank R with no other truncation.
- Core precision P ∈ {float16, float32}. Cores are cast to P, and s is
  rebuilt from the cast cores (the decoder does exactly this), so core
  rounding error moves into the residual instead of being hidden.
- Configuration (R, P) with R ∈ {4, 8, 16} and both P is a per-record coder
  choice: all 6 are run and the smallest total stream is kept. The choice is
  stored in the header and charged.
- Core blob: cores flattened in order, coded with the best of the 4 coders
  (1 choice byte + 4-byte length).
- Residual r = x − mean − s, quantized and coded with the same integer stream
  coder (all transforms). Residual q is bisected so the hybrid's decoded
  relative error is within ±2 % of the baseline's measured relative error.
- Stream bytes = magic(4) + n(4) + mean(8) + q(8) + d(1) + P(1) + 16 rank
  bytes + core blob + residual integer stream.
- If any cast core is non-finite, or no configuration reaches the error
  window, the record is INVALID (reported, not a win).

## Controls (from §4)
- Positive: the noiseless three-tone signal of the 2026-11-03 probe (48 kHz
  time base). Hybrid/baseline < 1 required, else the whole run is INVALID.
- Negative: white Gaussian noise, seed 20261104, unit variance. Hybrid/
  baseline ≥ 0.95 required, else the whole run is INVALID.

## Verdict rules (from §4, restated)
- Win on a record: hybrid bytes ≤ 0.95 × predictor-baseline bytes.
- F1 FAIL if wins < 4 of 7. F3 FAIL if median ratio (vs predictor baseline)
  ≥ 1.00. F2 FAIL if wins vs the no-predictor baseline are ≥ 4 but wins vs
  the predictor baseline are < 4. H1 holds only if no F fires and both
  controls are valid.
